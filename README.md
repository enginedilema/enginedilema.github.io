# Oriol Miró — Portfolio

Porfoli professional d'Oriol Miró.

**Formació · Desenvolupament · Intel·ligència Artificial**

Web estàtica desenvolupada amb [Astro](https://astro.build/) i publicada amb GitHub Pages.

## Desenvolupament local

```bash
npm install
npm run dev
```

Astro iniciarà el servidor local habitualment a:

```text
http://localhost:4321
```

## Comprovació del projecte

```bash
npm run check
```

## Build de producció

```bash
npm run build
```

El resultat es generarà dins del directori `dist/`.

## Publicació

Domini:

```text
https://enginedilema.github.io
```

El desplegament a GitHub Pages es configurarà mitjançant GitHub Actions.
